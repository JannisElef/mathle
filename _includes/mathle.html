How to play

Guess the hidden math equation. Each guess must be a valid equation that fits the row.

Colours

The character is in the right spot.
The character is in the equation but elsewhere.
The character is not in the equation.

Rules

Standard precedence applies: * and / before + and -. No floating-point steps - every intermediate result is a whole number. Equation must contain exactly one =.

Operators

Always available: + - * / =. From size 8 with extended mode: √ x² x³. √ takes the next number directly - typing √16 means √16 = 4.
